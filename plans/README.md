## Findings considered and rejected

- *Migration to React/Vue/Svelte or Next.js*: Considered and rejected. The zero-build single-file vanilla PWA architecture delivers instant boot on mobile, zero dependency overhead, and painless hosting on GitHub Pages.
- *Strict TypeScript compilation step*: Considered and rejected. Would introduce heavy build-step tooling (`tsc`, bundler, node_modules) into a purely static browser repository that benefits from zero-install deployment.
- *Removal of JSONP in favor of pure POST for reads*: Considered but deferred. Google Apps Script's `doGet` with JSONP bypasses CORS redirection limitations in older mobile WebViews reliably; keeping it while securing token queries and error handling preserves compatibility.
